Actúa como un experto desarrollador en Java y JavaFX. Necesito que generes el código fuente para una aplicación de escritorio llamada "Sistema Saludador" en JavaFX, siguiendo los requerimientos y la estructura de proyecto explicados a continuación.

### REQUERIMIENTOS Y FUNCIONALIDAD:
1. Caso de Uso Principal: "Solicitar saludo" (que incluye obligatoriamente "Pedir datos").
2. Flujo de la interacción:
   - El estudiante hace clic en un botón para solicitar un saludo.
   - El sistema le solicita ingresar: Nombre, Edad y Hora (en formato AM/PM).
   - El estudiante ingresa los datos solicitados.
   - El sistema muestra un saludo personalizado que incluye el nombre del estudiante y menciona su edad.
